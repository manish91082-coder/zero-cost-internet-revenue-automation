## 5. Candidate deterministic utility — IP/data provenance matrix
Candidate class remains a deterministic user-input utility/data validator/transformer. No specific product has been selected and no code has been built.

| Asset layer | Required provenance record | Release blocker |
|---|---|---|
| Product concept/specification | Dated original problem statement, requirements, author, prior-art search | Copying a competitor's distinctive expression/branding |
| Source code | File-level origin, author, commit history, AI-assisted sections, prompt/output record where relevant | Unclear ownership or copied proprietary code |
| Dependencies | Package name/version, SPDX licence, source URL, transitive dependency inventory, notices | Incompatible, unknown, non-commercial or source-available-only licence |
| Algorithms/formulas | Public-domain/standard source, independent implementation notes, attribution | Protected implementation copied from another Actor |
| Input data | User-provided / public-domain / licensed / generated; source URL and terms; personal-data classification | Scraped, restricted, confidential or unlicensed data |
| Output data | Whether user owns input/output; third-party database rights; attribution/redistribution restrictions | Claiming ownership of third-party data or violating database/API terms |
| Brand and listing | Name search, trademark/domain confusion review, explicit unofficial disclaimer for third-party services | Third-party marks/logo or misleading affiliation |
| Privacy/security | Data minimisation, no secrets, retention/deletion, logs, encryption, threat model | Unnecessary sensitive data collection or insecure retention |
| Apify integration | Actor terms, platform terms, end-user terms, billing model, user responsibilities | Unclear cost allocation or external payment circumvention |
| Release evidence | Licence scan, SBOM, tests under separately approved no-cost plan, legal review | Any unverified row or non-zero unfunded cost |

Minimum evidence bundle before release: source-code provenance manifest; SPDX SBOM; licence/notice bundle; data-source register; trademark review; privacy/data-flow diagram; security threat model; end-user terms; exact platform billing configuration; reproducible build/test evidence. This is a control framework, not legal advice or proof that any candidate already passes.
